## Terminology
- A `kubectl` **manifest** is a YAML file that defines a **Kubernetes resource**.  
- Common resources include **Deployment**, **Service**, **ConfigMap**, and others.  
- These manifests describe how containers and other components are deployed and managed within Kubernetes.
